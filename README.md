# pittsburghshit.com

The public site for **Pittsburgh Shit**, a weekly Pittsburgh events newsletter.

Three static pages, no build step, no dependencies:

| Page | What it does |
|---|---|
| `index.html` | Landing page with the subscribe form |
| `subscribe/index.html` | The URL printed in every email, Reddit comment and bio |
| `submit/index.html` | Reader-submitted events |

Forms POST to a Supabase edge function (`signup`), which handles double opt-in
confirmation, one-click unsubscribe, and event submissions. No secrets live in
this repo; the only external URL here is that function's public endpoint.

Generated by `scripts/build_site.py` in the (private) pipeline repo. Edit the
generator, not these files.
